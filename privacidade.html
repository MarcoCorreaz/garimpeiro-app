Política de Privacidade

Aplicativo Garimpeiro do Precinho. Última atualização: 11 de outubro de 2026.

Quem é o responsável

O Garimpeiro do Precinho é um aplicativo pessoal, mantido por Marco Corrêa, que automatiza a publicação de promoções em um canal do Telegram. Contato: contato.marcocorrea@gmail.com.

Quais dados do Google o aplicativo acessa

O aplicativo pede acesso à conta Google do próprio dono, apenas para o Google Planilhas. Ele lê e atualiza uma planilha específica, a lista de ofertas do canal: produto, preço, link, status e data de postagem. Ele não acessa e-mails, contatos, calendário, fotos ou outros arquivos.

Para que os dados são usados

  • Ler as ofertas aprovadas na planilha.
  • Publicar essas ofertas no canal do Telegram.
  • Marcar na planilha que a oferta foi postada.

Os dados do Google não são usados para nenhuma outra finalidade.

Compartilhamento e venda

Os dados da conta Google não são vendidos, não são compartilhados com terceiros, não são usados para publicidade e não são usados para treinar modelos de inteligência artificial. Só a oferta publicada (foto, preço e link do produto) aparece no canal do Telegram, que já é conteúdo escolhido para divulgação.

Armazenamento e segurança

As credenciais de acesso ficam guardadas na instalação do n8n do dono, em servidor sob o controle dele. O aplicativo não cria outro banco de dados com informações da conta Google.

Uso limitado

O uso e a transferência, para qualquer outro aplicativo, das informações recebidas das APIs do Google seguirão a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar o acesso

O dono pode remover o acesso do aplicativo a qualquer momento em myaccount.google.com/permissions. Depois disso, o aplicativo deixa de ler e atualizar a planilha.

Visitantes deste site

Este site não usa cookies, não tem formulários e não coleta dados de quem o visita.

Mudanças nesta política

Se algo mudar, esta página será atualizada e a data no topo, alterada.
